# Testimonials — Premium Catalog

---

## Variant 1: Editorial Pull Quote

**Best for:** Premium services showcasing testimonials with gravitas — no photos-in-circles, no carousel dots.

**Key features:**
- **Single large italic serif quote** dominates the 8-col left side. Opening quotation mark in terracotta 40% opacity, oversized.
- **Numbered navigator on right** (4 cols) — rows with number + author + org + hairline progress bar. Click to switch.
- **AnimatePresence transitions** — quote fades out, new quote mask-reveals line-by-line.
- **Author block** — hairline separator + uppercase name + italic serif role/org + uppercase location.
- **Active state on navigator** — number turns terracotta italic, text darkens, progress bar fills.

**Data shape:** `{ id, quote, author, role, org, location }`

See: `components/testimonials-variant-1.tsx`
