# Contact — Premium Catalog

---

## Variant 1: Editorial Contact Form

**Best for:** Premium brands, studios, private practices — a contact section that reads like correspondence, not a generic form.

**Key features:**
- **Asymmetric 12-col** — 5 cols copy, 7 cols form
- **Left side** — kicker + 2-line display heading (italic second line) + lead paragraph + availability block with left-border + postal address in italic serif
- **Right side form** — NO boxed fields. Each field is: uppercase small-caps label (animates color gray→black on focus) + transparent input + hairline bottom border (animates scaleX 0→1 in terracotta on focus)
- **2-col row** for name/email, then full-width organisation and message
- **Message field** — textarea with poetic placeholder ("Begin wherever feels natural…")
- **Submit button** — solid dark, inverts on hover, arrow slides right
- **Reading note** — micro-copy below button ("By sending, you agree to our quiet correspondence policy")

See: `components/contact-variant-1.tsx`
