## Variant 1: Editorial Story / Manifesto

**Best for:** Studio about page, founder letter, brand manifesto, origin story. Magazine-spread aesthetic — not a "Meet the team" grid.

**Key features:**
- **Chapter marker row** — italic "i." + "Chapter one · Origin" + studio name (hairline bottom border)
- **Three-line headline** — display serif, middle line italic
- **Two-column prose** — left starts with a huge italic drop-cap letter ("W"), right contains a **pull quote** mid-flow (italic serif in terracotta left-border) + continuation paragraphs
- **Signature block** — hairline + initials in italic display + uppercase founder/location meta
- **Per-paragraph mask reveal** with 80-100ms stagger tied to scroll

**What makes this different from a generic About:**
- Drop cap (editorial magazine signal)
- Pull quote mid-column (breaks the grid)
- Initials signature at end (personal, not corporate)
- No team photos
- Mixed typography (italic display + serif body + uppercase kicker)
