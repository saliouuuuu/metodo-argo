## 0. Prima di iniziare: la coerenza di Argo

Argo deve essere **lo stesso cane in ogni immagine**. Su Higgsfield:

1. Genera per prima `argo-ritratto.jpg` (prompt B1) finché non ottieni
   IL border collie giusto: quello è Argo, per sempre.
2. Usa quella foto come **riferimento personaggio** (funzione
   Character/Soul ID di Higgsfield) in tutti gli altri prompt con Argo.
3. Tieni fisso il blocco `[ARGO]` e il blocco `[STILE]` qui sotto:
   incollali all'inizio di ogni prompt dove compaiono.

**[ARGO] — blocco personaggio (in inglese, i modelli rendono meglio):**

```
Adult border collie dog, classic black and white coat, white blaze down
the face, warm intelligent amber-brown eyes, alert friendly expression,
one ear slightly folded, well-groomed medium-length fur
```

**[STILE] — blocco stile (identico ovunque):**

```
warm editorial photography, premium minimalist aesthetic, soft natural
window light, cream and warm beige background (#F7F2E8), muted sage
green and amber accent tones, shallow depth of field, shot on 85mm lens,
high detail fur texture, no text, no watermark
```

**Regole d'oro:**
- Niente testo dentro le immagini (l'AI lo sbaglia sempre: le scritte le mette il sito)
- Formato: indicato per ogni prompt (4:5 verticale, 1:1 quadrato, 3:2 orizzontale, 16:9 banner)
- Se una foto viene "plasticosa", aggiungi: `natural imperfections, candid moment, documentary style`
